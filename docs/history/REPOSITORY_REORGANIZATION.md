# 저장소 개편 기록

작성일: 2026-09-18.

> 역사 자료: 이 문서는 2026-09-18 개편 당시의 실행 기록이다. 당시 보관했던 이전 애플리케이션 폴더는 2026-09-22 현재 작업 트리에서 제거했다. 현재 구조와 실행 방법은 [문서 지도](../README.md), [아키텍처 지도](../ARCHITECTURE.md), [DEVELOPMENT.md](../DEVELOPMENT.md)를 따른다.

## 변경 결과

- 신규 개발 위치를 `app/`의 Next.js 단일 앱으로 고정했다.
- 당시 `backend/`, `frontend/`, 기존 인프라와 과거 팀 문서를 별도 보관 폴더로 이동했고 Git 기준 134개 파일의 내용 동일성을 검사했다. 해당 보관 폴더는 이후 현재 작업 트리에서 제거했다.
- 새 환경 예시는 `app/.env.example`, `infra/.env.example`로 분리했다.
- 루트 README·AGENTS, PRODUCT·TASKS·DEVELOPMENT를 추가했다. 11번 문서는 과거 기록임을 표시했고, 12번 계획에는 새 구현 위치와 초기 업종 범위를 반영했다.
- 공공데이터 검증 결과는 그대로 유지하고, 개인 PC 경로 대신 원본을 준비하여 재현할 수 있는 검증 안내를 추가했다.
- Next.js 시작 화면, 프로세스 health API, npm lockfile, 정적 검사와 빌드 CI를 구성했다.
- PostgreSQL 전용 Compose를 추가했다. 프로젝트명·볼륨·DB명을 분리하고 호스트 접속은 127.0.0.1:5433으로 제한했다.

## 보존 및 Git 상태

개편 당시 기존 DB 볼륨, 업로드, Git 이력은 삭제하지 않았다. 현재도 이전 코드의 이력은 Git에 남아 있으며 새 앱 의존성은 `app/node_modules`에서 관리한다.

이 개편에서는 자동 커밋·푸시·배포를 수행하지 않았다.
