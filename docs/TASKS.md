# TrendBench 마일스톤

이 문서는 마일스톤 단위의 완료 여부와 다음 순서만 기록한다. **개별 작업의 진행 상태·담당자·완료 여부의 원본은 GitHub Issue다.** 기능 PR은 이 파일을 수정하지 않고, 마일스톤의 마지막 Issue가 닫히면 이 파일을 갱신하는 작업 계약 Issue를 따로 만들어 한 PR로 반영한다. 제품·데이터의 현재 상태는 [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md), 과거 구현 과정은 Git 이력과 역사 문서를 따른다.

아래 미완료 항목은 작업을 시작할 때 [작업 계약 Issue](../.github/ISSUE_TEMPLATE/work-contract.yml)로 옮기고, 이 목록에는 Issue 번호를 붙인다.

## 완료 판정 규칙

- 코드가 존재하는 것과 운영 데이터가 사용 가능한 것을 구분한다.
- 실행하지 않은 테스트를 통과로 기록하지 않는다.
- DB suite가 건너뛴 검증은 DB 변경 완료 증거가 아니다.
- 자료 부족, 미검수, 외부 장애를 0건 또는 성공으로 표시하지 않는다.
- 체크 항목의 일부가 남아 있으면 상위 단계 전체를 완료로 부르지 않는다.
