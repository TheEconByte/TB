# ADR 0005: 공정위 가맹정보로 프랜차이즈 참고값 제공

- Status: Accepted
- Date: 2026-09-24
- Owners: jhjh0512
- Related issue/PR:
- Supersedes: 없음

## Context

`/api/franchises`는 자료가 없어 503을 반환했다. 가맹사업정보제공시스템의 "정보공개서 공개본 목록" API는 정보공개서 번호·가맹본부·브랜드·문서 링크만 준다. 비교에 필요한 가맹점 수·평균매출·창업비용이 없다.

공정거래위원회는 정보공개서에서 뽑은 수치를 공공데이터포털 Open API로 제공한다.

- **브랜드별 가맹점 현황**(`FftcBrandFrcsStatsService`): 가맹점 수, 신규 개점, 계약 종료·해지, 명의 변경, 연 평균매출, 3.3㎡당 연 평균매출. 업종은 대분류와 중분류로 나뉜다.
- **브랜드별 창업 금액 현황**(`FftcBrandFntnStatsService`): 정보공개서의 가맹점사업자 부담금인 가맹금, 교육비, 보증금, 기타, 합계. API 설명에는 항목 정의가 없다. 정보공개서 보도에 따르면 기타에는 인테리어·시설 집기·간판·비품 등이 들어간다(예: 메가커피 기타 5,159만 원). 2025년 범위 브랜드의 기타 중앙값은 약 7,100만 원이고, 합계는 네 항목의 합과 모두 같다.

2026-09-24에 실제 자료를 확인한 결과는 다음과 같다.

- **연도:** 기준년도(`yr`)는 정보공개서 연도이고, 수치는 그 전년도 실적이다.
  - `yr=2024` 빽다방의 평균매출 319,087(천원)은 보도된 "2023년 가맹점 평균 매출액 3억1908만원"과 같다.
  - `yr=2025`의 가맹점 수(빽다방 1,712, 메가커피 3,325)는 "2024년 말 기준"으로 보도됐다.
- **단위:** 금액은 천원이다.
- **최신 연도:** `yr=2026`은 아직 0건이다.
- **평균매출 0:** 가맹점이 있는데 평균매출이 0인 브랜드가 연도마다 약 1,500개 있다. 가맹점이 있는 브랜드의 연 평균매출이 실제로 0일 수는 없으므로, 미기재를 0으로 준 것이다.
- **현황 전체 0:** 가맹점 수·개폐점·평균매출이 모두 0인 행이 연도마다 약 2,000개 있다. 신규 브랜드일 수도 있지만 미기재도 섞여 있다. 예를 들어 `yr=2023` 메가커피 행은 모두 0이지만, 실제로는 2022년 말에 가맹점이 수천 개였다.
- **중복 이름:** 같은 법인·브랜드가 업종 중분류를 달리해 두 번 등록된 경우가 있다(예: 한식과 주점).
- **범위:** 제품 범위(외식 한식·커피·음료 커피 외)의 브랜드는 연도마다 약 4,500개다.
- **키:** 공공데이터포털 인증키 하나로 호출하지만 API마다 활용신청이 필요하다. 신청 전에는 403(`SERVICE_KEY_IS_NOT_REGISTERED_ERROR`)을 반환하고, 승인되면 같은 키로 호출된다.

## Decision

1. **적재:** 운영자 명령 `franchise:load`가 최근 3개 기준년도의 가맹점 현황과 창업 금액을 받는다. 기본 최신 연도는 한국 시간 기준 올해의 전년도다. 키는 공공데이터포털 인증키 `SEMAS_SERVICE_KEY`다.
2. **범위:** 외식 대분류의 한식(→ `CS100001`), 커피와 음료(커피 외)(→ `CS100010`)만 저장한다. 키는 기준년도·법인명·브랜드명·업종 중분류다.
3. **값 보존:**
   - 금액은 원본 천원 단위로 저장하고, API에서는 원 단위 정수 문자열로 바꾼다.
   - 평균매출과 3.3㎡당 평균매출의 0은 미기재(NULL)로 저장한다.
   - 가맹점 수·개폐점·평균매출이 모두 0인 해는 원본 값(0)을 그대로 저장한다. 다만 API가 `statusReported=false`로 표시하고, 화면은 "현황 없음(0 또는 미기재)"으로 보여 주며 전년 대비 증감을 계산하지 않는다.
   - 창업 금액은 다섯 값이 모두 0이면 미기재로 본다. 하나라도 있으면 개별 0은 받지 않는 항목으로 보고 0으로 둔다.
   - 창업 금액은 "정보공개서 창업 금액"으로 표시하고, 기타에 인테리어·설비 등이 들어갈 수 있으며 기준 점포 면적이 브랜드마다 다르다고 함께 적는다.
4. **검증:**
   - 응답 필드 구성과 기준년도가 요청과 같아야 한다.
   - 이름이 비었거나, 수치가 0 이상 정수가 아니거나, 키가 중복되거나, 연도 자료가 비었거나, 받은 행 수가 전체 건수와 다르면 적재하지 않는다.
   - 창업 금액은 같은 키로 잇고, 짝이 없는 행 수를 검증 요약에 남긴다.
5. **창업 금액 없이 적재:** 활용신청 승인 전에는 운영자가 `--without-startup-costs`로 명시해야만 창업 금액 없이 적재할 수 있다. 이때 릴리스 키에 `nocost`가 붙고 `startupCostsIncluded=false`가 된다. 화면은 창업 금액을 "이번 적재본에 없음"으로 표시한다.
6. **표시:**
   - 계획 화면은 사업 조건의 업종으로 가맹점 수 상위 브랜드와 검색 결과를 보여 준다.
   - 브랜드마다 가맹점 수(전년 대비), 연 평균매출과 월 평균(÷12), 3.3㎡당 연 평균매출, 개폐점, 창업 금액, 연도별 추이를 보여 준다.
   - 전국 평균이며, 재무 입력에 자동으로 넣지 않고 계산 결과에 저장하지 않는다(계약 3번).
   - 면적 × 3.3㎡당 평균매출 같은 개인 예상매출은 만들지 않는다.

## Alternatives considered

- **정보공개서 본문 파싱:** 기타 금액의 세부 내역(인테리어·기자재 등)과 기준 점포 면적을 알 수 있지만, 자동 문서 해석은 제외 범위다. 기각한다.
- **평균매출 0을 그대로 표시:** 미기재를 실제 0으로 위장한다(계약 2번 위반). 기각한다.
- **창업 금액 승인까지 기능 보류:** 가맹점 현황만으로도 비교가 가능하다. 대신 빠진 사실을 키와 화면에 드러낸다.
- **공정위 페어데이터 지역별 평균매출:** 학습데이터 형식이고 추가 신청이 필요하다. 이번에는 쓰지 않는다.

## Consequences

- 장점: 사용자가 같은 업종 브랜드의 규모·매출·개폐점·가맹본부 비용을 공식 수치로 비교한다.
- 비용·위험:
  - 적재 한 번에 약 20~30초, 요청 약 40회가 든다.
  - 브랜드·법인 이름이 연도마다 바뀌면 추이가 이어지지 않는다.
  - 공정위가 같은 기준년도를 나중에 고치면 새 릴리스가 된다.
  - 창업 금액 API 승인 전 적재본에는 창업 금액이 없다.
- migration·호환성: 새 테이블 2개(`20260924020000_franchise_benchmarks`). 기존 데이터는 바뀌지 않는다.

## Validation

- `app/src/features/franchise/franchise.test.ts`가 다음을 검증한다.
  - 기본 연도, 범위 필터, 필드·연도·숫자·이름·중복 거부, 조회 조건
  - 미기재 처리, 창업 금액 연결, `nocost` 키, 활용신청 오류(재시도 없음·키 가림), 빈 연도, 건수 변경
  - DB 활성화, 원 단위 변환, 검색, 연도 추이, 재적재
- `app/e2e/franchise.spec.ts`(데스크톱·모바일): 업종 선택 → 상위 목록 → 브랜드 선택 → 미기재 표시 → 검색·결과 없음 → 가로 넘침 없음.
- 2026-09-24 실제 적재: `ftc-franchise-2023-2025-2d36606bd8cb`, 브랜드 행 13,165건, 평균매출 미기재 1,844건, 창업 금액 연결 13,011건(짝 없는 창업 금액 행 0건). 활용신청 전에는 창업 금액을 뺀 `nocost` 릴리스로 적재했고, 승인 뒤 다시 적재해 대체했다.
