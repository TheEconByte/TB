# 제품

서울에서 음식점·카페 창업을 준비하는 예비 창업자가 공개 상권 관측값과 자신의 재무 가정을 분리해 보고, 필요자금·운영수지·대출 상환 부담·정책자금 후보를 판단하도록 돕는다. 기능을 바꾸는 PR은 [현재 기능](#현재-기능)을 같이 고친다. 범위를 바꾸려면 [ADR](decisions/README.md)을 먼저 쓴다.

## 원칙

1. **관측과 가정을 분리한다.** 서울시 매출은 시장 관측값이지 개인 예상매출이 아니다.
2. **집계 범위를 숨기지 않는다.** 매출은 서울시 상위 업종, 경쟁 점포는 소진공 세부 업종 기준이다.
3. **모르면 모른다고 표시한다.** `null`, `UNKNOWN`, 자료 부족, 후보 0건은 서로 다른 상태다.
4. **재현 가능한 결과를 남긴다.** 계산 결과에 입력 스냅샷·계산 버전·적용한 상품 버전을 저장하고, 계획에는 사용한 데이터 릴리스를 기록한다.
5. **승인처럼 말하지 않는다.** 자금 후보는 검토 시작점이지 대출 승인이 아니다.
6. **사용자가 적용을 결정한다.** 외부 조건은 명시적으로 선택해야 재무계획에 반영된다.
7. **근거 없는 정밀도를 만들지 않는다.** 정의가 불확실하면 계산하지 않거나, 근거가 있는 잠정 값임을 표시한다([ADR 0002](decisions/0002-provisional-market-sales.md)).

## 현재 기능

| 영역 | 제공 범위 | 기준 |
|---|---|---|
| 상권 분석(`/markets`, 공개) | 상권별 매출 금액·건수, 점포·개폐업, 요일·시간대·성별·연령대 구성 | 서울시 상권분석서비스 상위 업종, 2024년 1분기~2026년 2분기 |
| 경쟁 점포 | 자치구·세부 업종별 점포 수와 최대 50개 목록 | 소진공 상가(상권)정보 스냅샷 |
| 사업 조건 | 자치구, 상위·세부 업종, 면적, 층, 상가 유형 | 계획에 재무 입력과 분리해 저장 |
| 임대료 참고 | 조사 상권별 ㎡당 월 임대료(대표·층별), 공실률, 추이, 면적을 곱한 월 참고값 | 한국부동산원 상업용부동산 임대동향조사 서울, 2024년 3분기~2026년 2분기. 재무 입력에 자동으로 넣지 않음 |
| 재무 계획(`/`, 로그인) | 초기 비용, 자기자금, 매출·비용 가정, 부족자금, 운영수지, 손익분기, 상환 일정, 3개 시나리오 | 사용자가 입력한 가정만 계산 |
| 계산 결과 | 서버 재계산, 입력·버전·출처를 보존한 불변 결과 | 과거 결과를 수정하지 않음 |
| 자금 후보(`/funding`, 로그인) | 사업 단계·지역·업종·용도로 후보·미충족·미확인·종료·등록 이후 분류 | 운영자가 적재한 카탈로그만 사용. 검수자 미지정 상품은 현재 후보로 표시하지 않음 |
| 대출 가정 적용 | 확정 조건을 갖춘 현재 후보를 사용자가 선택해 재무계획에 적용 | 미확정·비대출 상품은 불가 사유 표시 |

상위 업종은 한식(`CS100001`)과 커피·음료(`CS100010`)만 노출한다.

## 제외 범위

- 세부 업종 매출·고객·배달 분석: 공식 출처가 없다.
- 월 환산과 점포당 매출: 공식 정의가 확정되지 않아 아직 제공하지 않는다. 확정 전에 제공할 때는 [ADR 0002](decisions/0002-provisional-market-sales.md)의 잠정 해석을 따른다.
- 프랜차이즈 비교: 검수된 데이터가 없어 `503 DATASET_UNAVAILABLE`로 응답한다.
- 특정 점포의 임대료 시세 추정: 부동산원 값은 조사 상권의 표본 평균이다.
- POS 연동, 예측 ML, 종합 점수, 신용 판단, 자동 승인, 지도, 주소 자동 매핑, 전국 확대, 자동 공고 해석
