# 프랜차이즈 참고 도메인

결정 배경은 [ADR 0005](../decisions/0005-ftc-franchise-reference.md)에 있다.

## 코드 위치

- `app/src/features/franchise`: 공정위 가맹정보 적재(`loader.ts`, `ftc-api.ts`), 서비스·업종 정의(`types.ts`), 조회(`read.ts`), 계획 화면 패널(`FranchisePanel.tsx`).

## 적재

- 실행: `npm --prefix app run franchise:load`.
  - 키는 `app/.env.local`의 `SEMAS_SERVICE_KEY`(공공데이터포털 일반 인증키, 소진공 적재와 같은 키)를 쓴다.
  - 공공데이터포털에서 [브랜드별 가맹점 현황](https://www.data.go.kr/data/15110241/openapi.do)과 [브랜드별 창업 금액 현황](https://www.data.go.kr/data/15110265/openapi.do)을 활용신청해야 한다.
- 기본으로 최근 3개 정보공개서 기준년도를 받는다. 최신 연도는 한국 시간 기준 올해의 전년도이고, `--latest-year 2025`로 바꿀 수 있다. 기준년도 N의 수치는 N−1년 실적이며, 가맹점 수는 N−1년 말 기준이다.
- 창업 금액 활용신청이 승인되기 전에는 `-- --without-startup-costs`로 창업 금액 없이 적재할 수 있다. 이때 릴리스 키에 `nocost`가 붙는다.
- 범위: 외식 한식 → `CS100001`, 커피·음료(커피 외) → `CS100010`. 키는 기준년도·법인명·브랜드명·업종 중분류다.
- 값:
  - 금액은 천원 단위 원본 그대로 저장한다.
  - 평균매출·3.3㎡당 평균매출의 0은 미기재(NULL)로 저장한다.
  - 가맹점 수·개폐점·평균매출이 모두 0인 해는 원본 0을 그대로 저장한다. 조회에서 `statusReported=false`가 되고, 화면은 "현황 없음"으로 표시하며 전년 대비 증감을 계산하지 않는다(예: 메가커피 2023년 기준년도).
  - 창업 금액은 다섯 값이 모두 0이면 미기재로 본다.
  - 창업 금액은 정보공개서의 가맹점사업자 부담금이다. 기타에는 인테리어·설비·집기·간판·비품 등이 들어갈 수 있고, 세부 항목과 기준 점포 면적은 브랜드마다 다르다.
- 다음 경우에는 활성화하지 않는다.
  - 필드 구성·기준년도 불일치
  - 빈 이름, 0 이상 정수가 아닌 수치, 중복 키
  - 빈 연도, 행 수 불일치
  - 활용신청하지 않은 API(`SERVICE_NOT_REGISTERED`)
- 같은 내용을 다시 받으면 `ALREADY_ACTIVE`다.

## 조회

`GET /api/franchises?industryCode=CS100001|CS100010&q=메가&limit=10`

- 최신 기준년도의 해당 업종 브랜드를 가맹점 수가 많은 순서로 돌려준다.
  - `q`는 브랜드명·가맹본부명의 부분 일치이며, 대소문자를 구분하지 않고 40자까지 받는다.
  - `limit`은 1~50이고 기본값은 10이다.
- 브랜드마다 최신 연도 값과 연도별 추이(`history`)를 준다.
  - 금액은 원 단위 정수 문자열이다.
  - 월 평균은 연 평균매출 ÷ 12를 원 단위로 반올림한 값이다.
  - 창업 금액이 적재되지 않은 릴리스에서는 `startupCosts`가 `null`이다.
- `summary`는 업종 브랜드 수, 가맹점이 있는 브랜드 수, 평균매출을 공개한 브랜드 수다.
- 활성 릴리스가 없으면 503 `DATASET_UNAVAILABLE`이다.

## 계획 화면

- 사업 조건의 업종으로 조회하고, 사용자는 브랜드를 검색·선택한다.
- 가맹점 수(전년 대비), 연 평균매출과 월 평균, 3.3㎡당 연 평균매출, 개폐점, 창업 금액, 연도별 추이를 보여 준다.
- 전국 평균이며, 재무 입력에 자동으로 넣지 않고 저장하지 않는다. 면적 × 3.3㎡당 평균매출 같은 개인 예상매출은 만들지 않는다.
