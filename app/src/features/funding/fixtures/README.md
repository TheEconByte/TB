# 자금 테스트 fixture

| 파일                  | 만든 방법                                                                                                                    | 넣은 문장(표는 행 순서)                                                                                                                                                                                                                             |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `notice.pdf`          | HTML을 Chrome headless `--print-to-pdf`로 인쇄. 글꼴은 Pretendard(OFL-1.1) 일부를 넣었다                                     | 2026년 소상공인 정책자금 융자 공고 / 신청대상: 업력 3년 미만 소상공인 (예비 창업자 제외) / 표 자금명·대출한도·대출기간, 혁신성장촉진자금·최대 2억원·5년(거치 2년 포함), 일반경영안정자금·최대 7천만원·5년 / ※ 음식점업은 신청 제외 업종이 아닙니다. |
